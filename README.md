## Public Projects

Personal demonstration repositories showcasing API design, architecture trade-offs, and implementation details:

- **[scalable-file-upload](https://github.com/Fael7s/scalable-file-upload)** — FastAPI demonstration service for file management with AWS S3, metadata persistence via SQLite/SQLAlchemy, temporary pre-signed download URLs, access logs, and automated tests. Includes documented technical trade-offs on memory buffering and transaction boundaries.
- **[bank-api](https://github.com/Fael7s/bank-api)** — Educational REST API built with FastAPI, SQLite, and SQLAlchemy. Features JWT authentication, bcrypt password hashing, account management, and transactional balance validations.
- **[taskflow](https://github.com/Fael7s/taskflow)** — Browser-based task management prototype built with vanilla JavaScript. Demonstrates event delegation, state synchronization, and persistent storage via `localStorage` with error handling for quota limits and corrupt state.
